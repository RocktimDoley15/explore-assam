# ExploreAssam 🌿

A responsive tourism website showcasing the beauty, culture, wildlife, heritage, and destinations of Assam.

## 🌄 About the Project

ExploreAssam is a travel and tourism website designed to help visitors discover beautiful destinations across Assam and Northeast India.

The website provides information about popular destinations, travel packages, reasons to choose the service, and an enquiry form.

## ✨ Features

- Responsive navigation bar
- Hero section with call-to-action
- Popular destinations section
- Travel packages
- Why Choose Us section
- About section
- Contact / enquiry form
- Hover effects
- Responsive design for desktop, tablet, and mobile

## 🗺️ Destinations

- Majuli
- Kaziranga National Park
- Manas National Park
- Sivasagar
- Guwahati
- Haflong

## 💼 Travel Packages

- Heritage Escape
- Wildlife Adventure
- Hills & Nature Retreat

## 🛠️ Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries
- Google Fonts

## 📱 Responsive Design

ExploreAssam is designed for:

- Desktop
- Tablet
- Mobile

The layout uses CSS Grid, Flexbox, and CSS media queries to adapt to different screen sizes.
